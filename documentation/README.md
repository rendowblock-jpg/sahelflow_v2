## Frontend direction now recorded

The target is not a fashionable reskin or a clone of another SaaS product. The
frontend must become a coherent operational system built on:

- deliberate Arabic/Latin typography and readable density;
- semantic design tokens and curated coordinated themes;
- restrained, reduced-motion-safe interaction motion;
- atomic AR/FR/EN and LTR/RTL transitions;
- logical RTL/mixed-direction geometry;
- shallow task-shaped navigation;
- compact severity-based notices;
- decision-rich charts;
- product-level Inbox, AI Agents and Settings workspaces;
- one shared component/state grammar adopted across the whole route inventory.

The Founder does not need to enumerate every remaining small UI defect. The
implementation team owns the complete route/component audit and root-cause
consolidation before broad frontend changes.
