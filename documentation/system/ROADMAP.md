Phase 5/6/7 closure and Phase 8 implementation to converge within one large,
dependency-correct implementation frontier instead of forcing repeated small
release loops before Phase 8 begins.

```text
post-Internal.15 authority reconstruction
→ Founder installed discovery + full source reconnaissance
→ one consolidated Problem Register
→ freeze shared contracts/non-goals/acceptance matrix

→ targeted cheap checks while coding

→ one consolidated repair batch

```

No broad application implementation starts until the current installed discovery is
closed by the Founder or explicitly frozen.

Existing measurement/query infrastructure remains protected. Internal.16 must certify
the final repaired product rather than measuring a superseded UI.

### T470 targets

- cold launch ≤ 8 seconds p95;
- ordinary navigation ≤ 700 ms p95;
- indexed search ≤ 350 ms p95;
- ordinary local mutation ≤ 500 ms p95.

### Declared floor targets

- usable shell ≤ 15 seconds p95 SSD / 25 seconds HDD;
- input acknowledgement ≤ 100 ms;
- navigation ≤ 1.5 seconds p95;
- indexed search ≤ 750 ms p95;
- local mutation ≤ 1 second p95;
- no ordinary freeze > 200 ms;
- steady working set ≤ 750 MB with WhatsApp connected;

- AI performance separates local SahelFlow/tool overhead from model/provider/network
  latency;
- images/charts/tables remain bounded on low-end hardware;
- final candidate completes the required eight-hour trend.
