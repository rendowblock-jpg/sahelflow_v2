# SahelFlow historical records

> **Status:** Preserved chronology and provenance; not active authority

This directory preserves former session, v3/v4 and implementation-history material whose exact wording remains useful for provenance.

Historical records may contain old prices, scope assumptions, provider plans, version labels, test counts, completion language or readiness claims. Interpret them only through the current active authority:

1. `../product/`
2. `../experience/`
3. `../architecture/`
4. current `CHANGELOG.md`, Working Memory and exact evidence

`LEGACY_SESSION_CHANGELOG.md` is the former root changelog preserved verbatim. Its entries document what contributors believed or implemented at the time. They do not establish current product scope, public version, provider support or Stable readiness.

Do not edit historical wording merely to make it current. Correct current truth in the active documents and preserve history as history.
