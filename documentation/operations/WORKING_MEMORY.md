## Active blockers and discontinuities

- Production confirmation still directly decrements mutable product stock rather
  than consuming canonical reservations and movements.
- Production routes do not yet adopt the independent order, confirmation,
  fulfillment, delivery, inventory, COD, return and refund contracts end to end.
- Commerce synchronization can advance its checkpoint after individual order
  persistence failures.
- Automations execute external effects directly and can report multi-step success
  despite failed steps.
- Seller identity, teams, devices, production licensing and native shop lifecycle
  remain incomplete.
- WhatsApp, courier and commerce integrations are candidates without complete
  durable inbox/outbox, replay, receipt and live-certification proof.
- Hosted storefront, remote PWA, shared cloud, zero-knowledge backup and Founder
  Console remain prototype, partial or missing.
- Whole-route AAA, Arabic/RTL, accessibility and low-end performance remain open.
