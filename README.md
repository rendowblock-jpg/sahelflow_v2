# SahelFlow

SahelFlow is a **Windows-first, local-first operations system for Algerian COD sellers**. It combines governed COD order intake, customer/product operations, delivery and returns, COD collection/remittance, Inbox/WhatsApp, automations, AI, analytics, settings, licensing, multi-shop, storefront/connected services and recovery under one protected authority model.
