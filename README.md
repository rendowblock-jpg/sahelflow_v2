# SahelFlow

SahelFlow is a **Windows-first, local-first operations system for Algerian COD sellers**. It combines governed COD orders, customer/product operations, delivery/returns, COD settlement, Inbox/WhatsApp, automations, AI, analytics, multi-shop, Storefront/connected services, licensing and recovery under one protected authority model.

## Why the product frontier changed

Internal.20 passed its selected technical gates, signed/runtime/install checks and publication path, but technical correctness did not produce Founder-approved product quality. The rejection exposed a design-process problem rather than a reason to weaken canonical business, data, native or release authority.

The 2026-08-16 Founder screenshot review then exposed a more specific RTL engineering failure: shell placement and `html[dir="rtl"]` can be correct while component internals remain wrong. The observed examples include Arabic navigation whose sidebar is on the right but icon/label order is still LTR, a Notifications popup whose portal/internal ordering remains LTR or mixed, and analytical surfaces where Arabic product chrome and chart internals use conflicting direction assumptions. Similar defects can be hidden across pages that otherwise look correctly mirrored.

The current work is therefore split into two paths:

1. **Structural RTL foundation — authorized implementation scope now.** Fix shared direction authority, portals/primitives, logical start/end geometry, directional controls, mixed-script bidi behavior and analytical direction domains. Prove actual primitive child geometry/computed direction, not only shell position.
2. **Inbox + AI Agents + Settings — full replacement product design.** Preserve protected jobs/data/provider/AI authority, but do not beautify the rejected workspace concepts into permanence. Define concrete English + Arabic Class-AAA information architecture and interaction targets and obtain Founder approval before broad reconstruction.

Acceptance hierarchy remains:

**Founder-installed visual judgment > side-by-side screenshot comparison > real interaction behavior > automated technical gates.**
